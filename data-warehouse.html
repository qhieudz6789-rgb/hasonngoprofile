Load Modeling

Composite load models are one of the most misunderstood pieces of a dynamic simulation study, and the ERCOT variants — CMPLDW2 and CMPLDWBLU — are commonly confused for one another. Both represent a mix of motor and static load behavior, but they diverge in how they're parameterized and where each is expected to be used.

CMPLDW2

CMPLDW2 is the standard WECC-style composite load model, representing a feeder-level mix of three-phase motors, single-phase motors (including air conditioning compressors), electronic loads, and static load. It has become the default choice for most transmission-level dynamic studies due to its ability to capture fault-induced delayed voltage recovery (FIDVR) behavior.

  • Includes distribution feeder equivalent impedance
  • Separately models single-phase AC motor stalling behavior
  • Widely accepted across WECC and increasingly adopted by ERCOT

CMPLDWBLU

CMPLDWBLU is an ERCOT-specific variant with adjusted default parameters tuned to better reflect the composition of load in the ERCOT footprint — notably a higher proportion of electronic and power-electronic-based load compared to the WECC default assumptions.

  • Same underlying structure as CMPLDW2, different default parameter set
  • Reflects ERCOT-specific load composition assumptions
  • Required in certain ERCOT interconnection study submissions

Why the Distinction Matters

Using the wrong variant — or the wrong default parameter set — can meaningfully change the simulated post-fault voltage recovery profile, which in turn affects whether a study shows compliance with FIDVR criteria. When submitting models for ERCOT studies, always confirm which composite load variant and parameter set is expected before running the final case, since mixing up CMPLDW2 defaults with CMPLDWBLU expectations is one of the more common review comments on submitted models.
